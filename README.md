# FlowGloss
FlowGloss是一个能安静且智能地为你当前页面提供你可能需要的知识解释的程序


## ✨ 核心特性

*   **无感伴读 (Non-intrusive)**：不抢占当前活动窗口焦点。系统在后台静默运行，注释弹窗随读随解。
*   **个性化边界 (Personalized)**：结合动态维护的用户知识画像，仅在你真正遇到知识盲区时才提供解释，拒绝无效打扰。
*   **低频与低耗 (Cost-effective)**：采用“事件驱动 + 增量提取”架构。通过底层事件监听和图像差分，规避高频截图与全量 OCR 带来的高 CPU 占用及 LLM API 的 Token 消耗。

## 🏗️ 核心架构

当前版本的核心流水线如下：
1. **捕获 (Capture)**：利用 `mss` 库以 1Hz 频率（或基于滚轮/键盘事件触发）获取屏幕特定区域图像。
2. **提取 (OCR)**：利用本地 `Tesseract` 引擎进行文本识别，保障基础数据隐私。
3. **判别 (LLM)**：结合 `config.json` 中定义的用户知识边界，调用大语言模型（如 DeepSeek、OpenAI）提取生僻概念。
4. **展示 (UI)**：通过半透明、置顶且无焦点的桌面悬浮窗展示最终解释。
