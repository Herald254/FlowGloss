# FlowGloss V1.0 推进记录

开发保持原有目录、中文模块指导说明与 Conventional Commits 格式。

## 本轮实现

- 工程基础：修复 pip/YAML 文件、统一 main.py、环境变量与本地覆盖、保留 CPU/GPU 安装入口。
- 手动闭环：截图、OCR、LLM、悬浮窗连接；明确本地错误、网络错误和无候选结果。
- 自动触发：接入监听、图像/文字去重、冷却、最新任务合并、过期结果丢弃。
- 记忆与缓存：SQLite 持久化、已掌握过滤、语境和模型配置隔离的解释缓存。
- 验证基础：队列、超时/重试、配置、持久化、窗口反馈与资源释放测试；Windows CI。

## 接下来的验收顺序

1. 配置真实 LLM 服务，在网页/PDF/编辑器中验证解释相关性、中文 OCR、混合排版与提示频率。
2. 验证不同显示缩放、多显示器、快速翻页、断网、运行中暂停和退出。
3. 根据反馈加入掌握记录管理、托盘和更方便的区域选择。
4. 测量 OCR 延迟、候选筛选成本和提示质量，再决定是否接入本地 NER 或多进程。
5. 最后优化增量识别、流式解释和视觉效果。

历史设计稿保留，但性能节省比例、GPU 加速和高级学习能力均是规划，不能作为验收证据。

## 第一版验收标准

- 安装和启动说明可执行；缺少配置有明确提示。
- 手动识别结果能显示，GUI 不执行 OCR 或网络请求。
- 同一静止页面不重复请求；页面切换不会显示过期任务结果。
- 暂停后无新截图/请求，退出后无遗留工作线程。
- 已掌握标记与解释缓存重启后保留；不同语境不误用缓存。
- 自动测试无 API 调用费用；真实服务验收需要另行配置本地密钥。
